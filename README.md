# UHC in Drehmal

Mostly implemented by me, with the RNG (LCG) module taken from [Cloud Wolf](https://cloudwolfyt.github.io/pages/downloads/list.html).

Key adjustable things:

- List of towers to spawn players at (`uhc:rng/init`)
- Death effects (`uhc:on_death`)
- Scheduled events, start/end time (`uhc:time/*`)
- Teleportable towers (`uhc:terminus_menu`)
- Border size and config (`uhc:border/setup`)
- Border shrink speed (`uhc:border/start_shrink`)

Made for Drehmal: Apotheosis 2.2.1 and Minecraft Java Edition 1.20.1.
